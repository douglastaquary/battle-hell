# Encounter plan — Abbey Clearing

**Format:** Arena circular ~16 m, FPS, landmarks: portão gótico (−Z), braseiros, árvores, lápides, caminho de pedra.

**Camera:** Eye-height 1.6 m, FOV 70, pointer lock desktop; joystick+FIRE em landscape mobile.

**Start:** Spawn em +Z olhando ao portão; intro 2.5 s → countdown 3 s → wave 1.

**First threat:** Esqueletos surgindo do chão / borda.

**First reward:** Abate com VFX osso+alma, score sobe, multiplier.

**Escalation:** Waves 1–5 conforme roster Rust (skeleton → reaper → ghoul/skull → knight → warlord-lite no web).

**Recovery:** Intermissão 6 s +25 armor.

**Telegraphs:** Rise do chão, silhueta no fogo, (áudio TBD).

**Modular:** `maps/*.json` + prop kit GLB; weather no editor.
